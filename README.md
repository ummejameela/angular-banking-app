# 🏦 Angular Banking App

This is a simple banking dashboard built with **Angular 15+**.  
It supports adding, editing, deleting bank account records and implements pagination, authentication, and localStorage.

## 🚀 Features

- ✅ Add/Edit/Delete Account Entries
- ✅ Pagination (manual)
- ✅ Authentication Guard using token
- ✅ LocalStorage data management
- ✅ Angular Service for Data Sharing
- ✅ Reusable Components

## 🛠️ Tech Stack

- Angular 15+
- HTML/CSS
- TypeScript
- RxJS
- LocalStorage (temporary DB)
